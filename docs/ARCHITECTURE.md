# المعمارية

## المبدأ

> **تحقّق مرّة من الإنسان → امنحه مفتاحًا سرّيًا يبقى في جهازه → يوقّع به محتواه → أي طرف يتحقّق بالمفتاح العام دون كشف بيانات.**

## المكوّنات الأربعة

| المكوّن | وظيفته | الحالة |
|---|---|---|
| بوابة الإنسانية | تثبت أن المستخدم إنسان (بلا كشف بيانات) | محاكاة |
| وحدة الإصدار | تولّد مفتاحين: سرّي + عام | ✅ |
| وحدة التوقيع | تختم المحتوى (C2PA-style manifest) | ✅ |
| وحدة التحقّق | تتحقّق من الختم وتكشف التعديل | ✅ |

## التقنيات

- **Ed25519** — التوقيع الرقمي (معيار عالمي مثبّت).
- **SHA-256** — بصمة المحتوى.
- **C2PA / Content Credentials** — معيار مفتوح لبيانات أصل المحتوى (نبني فوقه، لا نخترع بديلًا).
- **Zero-Knowledge Proofs** — لإثبات الإنسانية بلا كشف الهوية (المرحلة المتقدّمة).

## تدفّق العمل

```
المستخدم → [إثبات إنسانية] → [مفتاح سرّي + مفتاح عام]
        → [ختم المحتوى] → [نشر]
        → أي طرف → [تحقّق بالمفتاح العام] → ✅ / ❌
```

## مبادئ التصميم (غير قابلة للتنازل)

1. لا نخترع تشفيرًا من الصفر — نبني فوق المعايير.
2. لا نخزّن بيانات شخصية — كلّما قلّ التخزين، زادت الثقة.
3. المفتاح السرّي لا يغادر جهاز المستخدم.
4. التحقّق عام ومفتوح لأي طرف.
