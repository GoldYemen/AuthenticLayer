# AuthenticLayer 🛡️

> **طبقة مفتوحة المصدر لإثبات الأصالة والإنسانية**
> تُثبت أن المحتوى من إنسان حقيقي، لا مُولَّد بالذكاء الاصطناعي — دون تخزين أي بيانات شخصية.

[الرخصة MIT](LICENSE) · [المساهمة](CONTRIBUTING.md) · [المعمارية](docs/ARCHITECTURE.md)

---

## ما هي هذه الطبقة؟

محرّك يعمل في الخلفية (لا مجرّد موقع):

1. **بوابة الإنسانية** — تتحقّق مرّة واحدة أن المستخدم إنسان (بلا كشف بياناته).
2. **وحدة الإصدار** — تُصدر مفتاحين: سرّي (يبقى في جهاز المستخدم) + عام (يُنشر).
3. **وحدة التوقيع** — تضع ختمًا رقميًا على المحتوى لحظة إنشائه.
4. **وحدة التحقّق** — أي طرف يتأكّد من الختم بنقرة، ويرى ✅ أو ❌.

> القاعدة الذهبية: **لا نخترع تشفيرًا** — نبني فوق معايير عالمية مثبّتة (Ed25519، C2PA)، و**لا نخزّن بيانات شخصية**.

## البنية

```
authenticlayer/
├── core/            النواة: توليد المفاتيح + التوقيع + التحقّق
├── api/             خادم التحقّق (FastAPI)
├── verify/          صفحة تحقّق عامة (HTML/JS)
├── extension/       إضافة المتصفّح
├── docs/            المعمارية وخارطة الطريق
└── .github/         قوالب المسائل + سير العمل (CI)
```

## التشغيل السريع

```bash
# ١) النواة
python core/authentic_core.py

# ٢) خادم التحقّق
pip install -r requirements.txt
uvicorn api.server:app --reload
# ثم افتح  http://127.0.0.1:8000/verify
```
